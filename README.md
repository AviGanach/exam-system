# 📚 מערכת מבחנים מקוונים - Online Exam Platform

מערכת מתקדמת ליצירת וניהול מבחנים מקוונים עם תכונות אנטי-רמאות, בנויה עם React + TypeScript ו-Python Flask.

## 🎯 תכונות עיקריות

### 🤖 בינה מלאכותית מובנית
- **בדיקת שאלות פתוחות בAI** - הבנה ועיבוד של תשובות בשפה הטבעית
- **הערכת קוד מתקדמת** - ניתוח נכונות, יעילות ועמידה בקונבנציות
- **ציון אוטומטי מדויק** עם משוב מפורט
- **למידת דפוסים** מתשובות נכונות ושגויות

### 👨‍🏫 למורים
- **יצירת מבחנים** - ממשק אינטואיטיבי ליצירת מבחנים מותאמים אישית
- **סוגי שאלות מגוונים**:
  - שאלות אמריקאיות (בחירה מרובה)
  - שאלות פתוחות
  - שאלות קוד (Python, JavaScript, Java, C++)
- **הגדרות מבחן מתקדמות**:
  - זמן מבחן עם טיימר ויזואלי
  - הצגת ציון מיידית
  - מעקב אחר מעברים בין חלונות/כרטיסיות
  - הגדרת תאריכי פתיחה וסגירה
- **ניתוח תוצאות** - דוחות מפורטים על ביצועי התלמידים

### 👨‍🎓 לתלמידים
- **גישה קלה למבחן** - הזנת קוד מבחן פשוטה
- **ממשק נוח ומעוצב** - חווית משתמש אופטימלית
- **מעקב זמן חזותי** - טיימר עם התרעות
- **עורך קוד מתקדם** - עם highlight syntax
- **אנימציות ואפקטים** - חוויה מעניינת ומרגשת

### 🔒 אבטחה ואנטי-רמאות
- **מעקב מעברים בין כרטיסיות** - זיהוי אוטומטי של עזיבת המבחן
- **מדידת זמן מחוץ למבחן** - חישוב מדויק של זמן היעדרות
- **טיימר עמיד בפני רמאות** - לא ניתן לעצור או להאט
- **התרעות בזמן אמת** - הודעות למשתמש על מעקב
- **רישום פעילות מפורט** - לוגים למורה

## 🛠 טכנולוgiות

### Frontend
- **React 18** עם TypeScript
- **CSS3** עם אנימציות מתקדמות
- **Web Audio API** לאפקטי קול
- **Router** לניווט
- **Responsive Design** לכל המכשירים

### Backend
- **Python Flask** עם ארכיטקטורת שכבות
- **JWT Authentication** לאבטחה
- **MySQL** למסד נתונים
- **Blueprint Architecture** לארגון קוד
- **Logging** מפורט

## 🚀 התקנה והרצה

### דרישות מערכת
- Node.js 18+
- Python 3.9+
- MySQL 8.0+

### התקנת Frontend
```bash
cd frontend
npm install
npm start
```

### התקנת Backend
```bash
cd backend
pip install -r requirements.txt
python app.py
```

### הגדרת מסד נתונים

```sql
mysql -u root -p exam_platform < sql/insert_sample_data.sql
```

## 🎨 תכונות מתקדמות

### אנימציות ואפקטים
- **פיצוץ כפתור שליחה** עם אפקטי קול רב-שכבתיים
- **אנימציות טעינה** בעיצוב רקטה וכוכבים
- **מעברים חלקים** בין דפים ורכיבים
- **התרעות ויזואליות** בזמן אמת

### מערכת ציונים חכמה מבוססת AI
- **בדיקה אוטומטית** של שאלות אמריקאיות
- **בדיקת AI מתקדמת** לשאלות פתוחות - ניתוח תוכן ומשמעות
- **הערכת קוד בAI** - בדיקת נכונות, יעילות ואיכות קוד
- **ציון משוקלל** לפי נקודות השאלות
- **משוב AI מפורט** למורה ולתלמיד

### אבטחה מתקדמת
- **הצפנת סיסמאות** עם bcrypt
- **JWT tokens** עם פקיעה אוטומטית
- **ולידציה מקיפה** של קלט משתמש
- **מניעת SQL Injection** ו-XSS

## 🎯 זרימת עבודה

### למורה
1. **התחברות** עם סיסמת מורה
2. **יצירת מבחן חדש** או עריכת מבחן קיים
3. **הוספת שאלות** מסוגים שונים
4. **הגדרת פרמטרים** (זמן, אנטי-רמאות, וכו')
5. **פרסום המבחן** וקבלת קוד מבחן
6. **מעקב תוצאות** וניתוח ביצועים

### לתלמיד
1. **הזנת קוד מבחן** שקיבל מהמורה
2. **צפייה בפרטי המבחן** לפני התחלה
3. **ביצוע המבחן** עם מעקב זמן
4. **שליחת המבחן** עם אנימציה מגניבה
5. **קבלת תוצאה** (אם הוגדר כך)
